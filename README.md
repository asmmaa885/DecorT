# DecorT – Handcrafted Home Décor
A responsive e-commerce landing page for handcrafted mirrors, lighting, and sculptural home décor, built with HTML, CSS, and JavaScript. Features a modern UI, product showcase, shopping cart, customer reviews, and newsletter section.

## Live Demo
[View DecorT Website](https://asmmaa885.github.io/decort/)

## Features
- Modern and responsive landing page design
- Handcrafted product showcase
- Shopping cart interface
- Customer reviews section
- Newsletter subscription interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Purpose
This project was created to explore and demonstrate frontend web development, UI design, and e-commerce website layout.

## Note
This is a frontend demonstration project. Shopping cart and newsletter interactions are UI demonstrations and are not connected to a backend or payment system.
